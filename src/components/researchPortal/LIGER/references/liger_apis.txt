LIGER APIs

BASE DOMAIN: varies by the portal hosting this component. Both of these are valid,
and others may be added:
  https://bioindex-dev.pankbase.org
  https://bioindex-dev.hugeamp.org
Examples below use pankbase, but the domain is not part of the API contract —
only the path and query schema are.

All endpoints are called as:
  {BASE}/api/bio/query/{endpoint}?q={comma-separated schema values}

- - - - - - - - - -

ENDPOINT INDEX (endpoint / bioindex table / schema)

single-cell-lognorm                        SingleCellLogNorm                     dataset,gene
single-cell-gene                           SingleCellGene                        gene
gene-program-expression-cell-state         GeneProgramExpressionAllCellState     gene
gene-program-expression-cell-state         GeneProgramExpressionCellState        dataset,cell_type,gene
gene-program-expression-program            GeneProgramExpressionAllProgram       gene
gene-program-expression-program            GeneProgramExpressionProgram          dataset,cell_type,model,gene
gene-program-expression-cell-type          GeneProgramExpressionCellType         dataset,gene
gene-program-heatmap                       GeneProgramHeatMap                    dataset,cell_type
gene-program-factor                        GeneProgramFactor                     dataset,cell_type,model
gene-program-gene-factor                   GeneProgramGeneFactor                 dataset,cell_type,model,factor
gene-program-trait-factor                  GeneProgramTraitFactor                dataset,cell_type,model,factor
gene-program-cell-state-trait-factor       GeneProgramCellStateTraitFactor       dataset,cell_type,state_name
gene-program-cell-state-metadata           GeneProgramCellStateMetadata          tissue,cell_type
gene-program-cell-state-metadata-extended  GeneProgramCellStateMetadataExtended  tissue,cell_type
gene-program-qc-factor                     GeneProgramQCFactor                   dataset,cell_type,model,factor
gene-program-qc-metadata                   GeneProgramQCMetadata                 dummy
gene-program-qc-metadata-extended          GeneProgramQCMetadataExtended         dummy

NOTE: gene-program-expression-cell-state and gene-program-expression-program each
back two tables. The single-argument (gene only) form returns all datasets / cell
types; the multi-argument form narrows to one dataset + cell type.

NOTE: most endpoints now key on a dataset ID (e.g. islet_of_Langerhans_scRNA_v3-4)
rather than a plain tissue name. The two cell-state-metadata endpoints are the
exception and still take tissue (e.g. pancreas).
